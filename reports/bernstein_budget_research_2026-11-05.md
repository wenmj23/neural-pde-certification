## 研究问题与边界

这次区分两个容易混淆的操作：**PDE 网格段数**决定残差在哪些小区间重构；**Bernstein 细分深度**只在每个已有单元内部，通过细分辅助多项式系数来估计其连续最大值。后者不增加 PDE 网格段数，也不是提高残差重构次数。

助手在 Linux / Python 3.12、python-flint 0.9.0 执行；所用均为已有冻结网络或人工构造函数。证书依赖零边界、导数区间包含、实现及区间后端正确性，当前没有独立形式化审计，用户尚未在 Windows 复现本轮。范围紧度 U/L≤1.02 反映界的紧窄，不是网络实际误差小于 2%。

## 第一轮：固定 PDE 网格，更改单元内部估计深度

运行前固定 `configs/bernstein_depth_2026-11-05.json`：12 个已有正弦 PINN（k=1/3/5、深度 1/2、种子 501/502），重构二次或三次，PDE 网格 32 或 64 段，Bernstein 深度 0、1、2、3、4，单独新建问题和验证器，共 **240** 条范围。数据集和先前结果已经可见，不能当作新网络盲测。参考值在证书计算后读取；240/240 均包含已有的收敛连续参考区间。

| 重构 / 段数 | 深度 0 的 U/L≤1.02 达标 | 深度 2 达标 | 深度 4 达标 | 深度 4 范围宽度 / 深度 0 范围宽度的逐网络中位数 |
| --- | ---: | ---: | ---: | ---: |
| 二次 / 32 | 2/12 | 2/12 | 2/12 | 0.998 |
| 二次 / 64 | 3/12 | 3/12 | 3/12 | 0.994 |
| 三次 / 32 | 3/12 | 3/12 | 3/12 | 0.967 |
| 三次 / 64 | 8/12 | 9/12 | 9/12 | 0.709 |

中位数为先按同一网络配对计算范围宽度之比，再对 12 个比值求中位数。比如三次/64 的 0.709 表示此批范围宽度的配对中位比约为 70.9%，不是预测误差降低 29.1%。相同 PDE 网格和次数下，全部 192 对相邻深度比较中没有发现范围宽度变大，神经残差和导数区间的调用计数相同。受区间舍入与实现影响，不能把有限观测提升为所有问题必然逐项单调的证明。

相对已有默认深度 2，改为深度 4 的 12 网络配对范围宽度中位比分别为：二次/32 0.99987、二次/64 0.99939、三次/32 0.99607、三次/64 0.97938；个别网络改善大于中位水平。深度 0 与 4 在本轮 48 个网络/次数/网格配置、6 个固定容差上，288 个判断均相同；三次/64 的范围紧度达标数由 8 增为 9。范围变窄并不一定改变容差判断。

深度 2 的 48 个网络、次数与网格组合，与之前 `shape_budget` 相应输出的有理上下端点 48/48 完全一致。这是同实现/同机输入的重复一致性，而不是独立审计。

## 第二轮：小样本计时

预先在 `configs/bernstein_timing_2026-11-05.json` 固定 3 个已有网络（k=1 浅层、k=3 深层、k=5 深层，均 seed501）、二/三次、64 段、深度 0/2/4；每配置 1 次预热、3 次计时，共 18 次预热和 54 次计时，每个重复轮次打乱配置次序。每次新建问题和验证器，仅计时 `certify()`，包含残差、导数区间与多项式计算，不含新建对象、解释器启动、保存和参考计算。运行期间环境非隔离，且有少量其他结果读取；这不是可推广的稳定基准。

每个网络和重构次数分别计算三个配对比值后取中位数：深度 2 / 0 约 **1.006–1.075**，深度 4 / 2 约 **1.053–1.163**。深度 4 比深度 2 的三个配对比中位数都大于 1，但样本量仅 3 个网络、每配置重复 3 次，机器负载会影响结果；不能从中推断所有问题的开销比例或最优深度。72 次预热和计时的生成过程检查了端点与第一轮相同设置的结果相同；读回检查了保存的键、时间、哈希和这些生成过程的标志，没有重新计算每次计时的区间端点。

## 第三轮：人工高频压力案例

构造连续误差 e(x)=10⁻⁴ sin(kπx)，k=16、32，解析最大绝对误差为 10⁻⁴。这些都是人工控制，不是训练所得 PINN。初始固定 32/64 段、二/三次和 Bernstein 深度 0/2/4，共 **24** 条范围，24/24 均包含解析值；高频部分范围很宽，例如 k=32 时 64 段的范围下界仍为零，无法满足 U/L≤1.02。仅加深 Bernstein 细分未使这些 k=32、64 段案例达标。

看到初始结果后，补测 128/256/512 段、深度 0/2，另 **24** 条范围全部包含解析最大值。再针对 k=32 二次 512 段仍不达标的现象补测 1024/2048 段，**2** 条也包含解析值。后两次预算均是观察后选择的探索性追查，不是预先注册的盲测：

| 人工频率 / 重构 | PDE 段数 | Bernstein 深度 | U/L 约 | 范围紧度达标 |
| --- | ---: | ---: | ---: | --- |
| k=16 / 三次 | 64 | 2 | 1.059 | 否 |
| k=16 / 三次 | 128 | 2 | 1.0032 | 是 |
| k=32 / 二次 | 512 | 2 | 1.072 | 否 |
| k=32 / 二次 | 1024 | 2 | 1.0083 | 是 |
| k=32 / 三次 | 128 | 2 | 1.260 | 否 |
| k=32 / 三次 | 256 | 2 | 1.0128 | 是 |

在这些特定人工高频问题中，单纯加深多项式估计没解决粗 PDE 网格造成的主要松弛，而增加网格段数能明显改善。不能由此声称所有真实 PINN 或更一般 PDE 都有相同表现。
