## 一条命令做只读核查

从仓库根目录运行，建议 Python 3.12 的独立环境：

```bash
python -m pip install -r requirements-audit-nov12.txt
python scripts/313_verify_nov12_bundle_20261112.py
```

脚本校验 [publication_manifest.json](publication_manifest.json) 的 370 个文件哈希，在临时目录只复制清单文件，运行十个原始读回脚本，并要求生成的读回报告与归档逐字节一致。它不修改本仓库中的结果，也不重新执行全部数值内核。清单包括本批脚本、配置、逐例明细及必要的已有冻结输入/基线；清单哈希不构成防恶意篡改的签名，也不证明数学正确性。

同步准备时已在最新 main 的独立克隆中通过上述核查，详见 [publication_validation.json](publication_validation.json)。这是 Linux 环境检查，不是 Windows 实测，也不将其他日期未公开实验自动变成可复现。

## 重新计算与历史证据的区别

历史生成脚本默认拒绝覆盖固定结果目录。若重新计算，在一次性工作副本中保留相应输入和配置，只将要重算的那一组结果移出该副本，再执行对应生成和读回脚本；原始仓库档案保持不动。例如非负控制按 298→299，Green 多项式点检按 296→297。12 号旧入口支持 `--out <新目录>`，306 号读回使用表中固定相对路径。

有依赖的实验读取锁定输入哈希：302、307、311 使用 294 的旧选点文件，309 使用 307 的旧记录。新的数值运行可能因时间/平台元数据而产生不同哈希；如要串联一整套全新计算，必须建立新的配置和结果版本，并记录新输入哈希。不能把旧配置静默改成新哈希后称为原始结果复现。当前清单和原始检查提供的是已归档证据的可移植核查。

依赖版本：mpmath 1.3.0、NumPy 2.3.5、SymPy 1.14.0；本次 Python 3.12.14。原 Arb 主线应另用 `requirements-certifier.txt`，不能把本日另一后端的检查当作该主线已重算。完整历史 ZIP、私人报告原件、旧异常目录和无关大文件不在本次范围。
