# 2026-11-27 半点研究：四次和五次 Bernstein 范数控制

本包核查连续范数包围所用的 `norm_enclosure` 函数，针对形如 `(x-a)^n+b` 的人工多项式，其中次数 n 为4或5，a 取0、1/2、1，b取 -1/8、0、1/8，细分深度取0至4。端点及已知驻点上的精确有理值给出这些特殊函数的连续最大绝对值。

在 Linux、Python 3.12、python-flint 0.9.0、mpmath 1.3.0、Arb 103位下，90/90次计算的上下界包含精确范数，且每个函数的下界随细分深度不下降。非法深度 -1 被拒绝。输出明细和统计分别在 `rows.json`、`summary.json`。这是18个人工函数的有限控制，不是90个独立网络，也不是对任意四次/五次函数、网络残差重构或完整验证器的形式化证明。

运行：在本目录执行 `python audit.py`。脚本会重写本目录的 `rows.json` 和 `summary.json`，如需保留此处原始结果，应先复制整个目录到新位置再运行。`scripts/` 是执行所需的当时源码副本，原始文件和配置哈希见 `SHA256SUMS`。本轮研究由助手执行，用户 Windows 未复现。

数学依据：每个子段端点属于整个连续域，因此端点绝对值的可靠下界也是全域范数下界；Bernstein 系数凸包给出多项式的上界。对于非精确输入、上游残差重构、余项传播和区间后端，仍分别依赖相应实现与数学假设正确。
