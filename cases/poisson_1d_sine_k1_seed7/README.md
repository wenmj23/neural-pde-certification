# 固定主案例：一维正弦源项 Poisson PINN

此案例作为后续验证器检查的固定输入。已在 2026-10-28 完成权重提取、来源核对和重新加载复现；本次没有重新训练网络。工作文件已纳入 2026-10-28 日终归档，按约定统一同步 GitHub。

## 方程与网络

\[
-u_*''(x)=\pi^2\sin(\pi x),\quad x\in[0,1],\qquad u_*(0)=u_*(1)=0.
\]

用于参考比较的已知精确解为 \(u_*(x)=\sin(\pi x)\)。验证器构造上界时不使用这个精确解。

冻结的 PINN 输出为

\[
v(x)=x(1-x)\left[c+\sum_{j=1}^{16}a_j\tanh(w_jx+b_j)\right].
\]

网络结构为 1→16→1，共 49 个参数。乘子 \(x(1-x)\) 使网络在两端满足零边界。参数保存为 JSON，重新加载为 float64；后续实函数区间研究将这些二进制浮点权重当作精确常数，推理运算的舍入误差单独处理。

## 选择和训练来源

该输出已用于此前的方法比较及区间原型，保留它便于前后对照。它是一个误差较小、已有记录的具体案例，不能代表所有 PINN 的表现。

- 来源：`scripts/05_cross_problem_validation.py` 中 k=1、seed=7、训练 2000 步后的模型。
- 单隐层 tanh，float64，CPU；Adam，显式设置学习率 0.01，其余选项采用原记录环境下的默认值。
- 固定内部训练点 \(x=j/129\)，\(j=1,\ldots,128\)。
- 损失为这些点上残差 \(-v''-\pi^2\sin(\pi x)\) 的均方。
- 已保存原批次配置、训练脚本哈希以及第 0、100、500、2000 步的验证记录。原实验没有保存每一步的 loss 或优化器状态，不能把这些记录称为完整训练轨迹，也不支持从该优化器状态续训。
- 重新加载固定权重无需训练；不承诺不同平台或软件版本下从随机种子重新训练可以逐位得到相同参数。

## 冻结的参考结果

在包含端点的 10001 个均匀网格点上，观察到

\[
E_{\mathrm{grid}}=1.0329992292423817\times10^{-4},
\]

最大误差所在网格点为 \(x=0.5264\)。**这是网格观测最大值，不能称为连续区域上的精确最大误差。**

以下结果使用普通 float64；“倍数”均为上界除以上述网格参考误差，尚未考虑机器级向外舍入认证。

| 残差检查区间数 | 常数重构上界 / 参考误差 | 直线重构上界 / 参考误差 |
|---|---:|---:|
| 128 | 5.351109 | 1.043998 |
| 512 | 1.452859 | 1.001996 |
| 1000 | 1.179099 | 1.000491 |

1000 个区间下，直线重构的误差上下界计算值为

\[
[1.032341399679322\times10^{-4},\;1.0335065200125773\times10^{-4}].
\]

这是一组待进一步审查舍入误差的浮点结果，不作为机器级严格证书。

重新加载后，在另选的 257 个点上，PyTorch 与 NumPy 的网络值最大差异约为 \(2.22\times10^{-16}\)，残差最大差异约为 \(3.11\times10^{-15}\)；两端输出为 0。此交叉核对有助于查找加载和公式错误，不能代替严格数值分析。
