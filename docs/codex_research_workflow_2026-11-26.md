## 首次环境检查（Windows PowerShell）

在已有的项目仓库根目录，先检查 `git status`；保留未提交文件，不使用 reset、clean 或强制推送。确认环境版本后，在独立虚拟环境安装现有公开验证器的依赖：

```powershell
python --version
 git status --short --branch
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-certifier.txt
.venv\Scripts\python.exe scripts/agent_preflight_20261126.py
```

如果 `.venv` 已存在，先检查它是否属于本项目，避免覆盖或破坏现有环境；若需要新环境，改用新的目录名。为一次试运行选择**不存在的新路径**：

```powershell
.venv\Scripts\python.exe scripts/agent_preflight_20261126.py --smoke-out ..\pde-smoke-first
```

试运行目录不得已存在。输出含结果目录，需查看 `result.json` 和报告。它只调用公开浅层案例，不训练网络，也不能证明验证器整体正确。2026-11-26 在 Linux/Python 3.12、python-flint 0.9.0 已试跑；Windows 尚未复现。若找不到 python-flint，记录 Python 版本和完整报错，不要假称安装成功。

## 运行和安全边界

- 先人工在普通 Codex 研究会话中运行一次，检查能否读代码、运行实验和生成记录；通过后再配置定时任务。任务可根据系统权限运行，权限不足或需要授权时会停下，不保证可绕过。
- 当前两条 ChatGPT 定时任务已经启用；在本机或另一云端建立新的自动运行前，应核对重叠时间与仓库并发写入风险。不要让多个 Agent 同时直接写同一分支；无法确认状态时先只读。
- 网页定时任务不保证跨运行保留本地目录。工作区必须视为可能消失；跨轮以已核验的 GitHub 记录和输入为准。
- 桌面本地定时任务依赖电脑和应用运行、网络与本机依赖；云端是否可执行由云环境、权限和套餐决定。不要声称已设置本机定时任务，直到实际创建并完成验证。
- 助手生成的推导、数值实验和论文材料都需要学生理解并和导师核对。今天 16 条结果只涉及两个已有网络，历史数据缺失的根因未明。
