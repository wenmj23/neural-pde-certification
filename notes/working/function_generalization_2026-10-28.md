# 直线残差重构：补充函数检查（2026-10-28）

本轮由助手运行，接续高频误差实验。工作记录现已纳入日终归档；学生复现和理解仍待后续进行。方法和公共核心保持不变，新增的是测试函数及其残差、导数上界适配器。

## 结论

补测了 8 个非零误差函数和 1 个零误差对照，在 8 种网格预算、3 种方法设置下共执行 216 个配置，数值检查均通过。结果支持：直线残差近似的改善不局限于单一正弦或中部高斯窄峰；对混合频率、非对称边界附近窄峰也有效。采样很粗时仍可能比常数方案更松，自适应对全域振荡仍可能增加总耗时。

这些是普通 float64 的受控实验检查，没有完成新的机器级严格认证。所有非零函数的连续最大误差在数学上精确已知；代码中的常数、三角函数和最大值归一化仍通过浮点求值，不能把小数结果直接当作向外舍入的证书。

## 测试构造与答案来源

固定真实解 \(u_*(x)=x(1-x)\)，即 \(-u_*''=2\)，边界为零。人为构造近似 \(v=u_*+e\)，因此验证器输入残差为 \(r=-e''\)。本轮没有训练神经网络；它检验现有认证算法对误差形状的适应性，不能替代神经网络导数上界适配器的检查。

非零误差的幅值均为 \(A=10^{-4}\)。

| 名称 | 误差 \(e(x)/A\) | 最大绝对值位置 |
|---|---|---|
| affine_residual | \(\frac{3\sqrt3}{2}(x-x^3)\) | \(1/\sqrt3\) |
| mixed_mild | \(\frac34\sin(\pi x)+\frac3{16}\sin(5\pi x)+\frac1{16}\sin(21\pi x)\) | \(1/2\) |
| mixed_signed | \(\frac12\sin(\pi x)-\frac14\sin(3\pi x)+\frac14\sin(41\pi x)\) | \(1/2\) |
| weak_high_tail | \(\frac{120}{128}\sin(\pi x)+\frac7{128}\sin(5\pi x)+\frac1{128}\sin(81\pi x)\) | \(1/2\) |
| broad_polynomial | \(x^2(1-x)^2/B\) | \(1/2\) |
| left_peak_1_16 | \(x(1-x)^{15}/B\) | \(1/16\) |
| left_peak_1_64 | \(x(1-x)^{63}/B\) | \(1/64\) |
| right_peak_63_64 | \(x^{63}(1-x)/B\) | \(63/64\) |

每个多项式型窄峰使用自己的归一化常数 \(B=(p/(p+q))^p(q/(p+q))^q\)。对 \(x^p(1-x)^q\) 求导可得最大值位置 \(p/(p+q)\)，故归一化后最大误差等于 \(|A|\)。混合正弦的系数绝对值之和为 1，且所有带符号分量在 \(x=1/2\) 同时贡献正峰，因此最大绝对值也精确等于 \(|A|\)。零误差对照单独设 \(e=0\)。

所有选点与停止条件均不使用这些已知答案。残差回调直接计算 \(-e''\) 的解析式；这避免了构造测试时将两个近似相等的大数相减。真实网络输出的残差计算误差是另一个需要单独处理的问题。

## 同样采样预算下的结果

均为 1000 个区间、1001 个残差采样点。表中为“上界 / 数学上精确已知的最大误差”，越接近 1 越紧。

| 对象 | 常数、均匀 | 直线、均匀 | 直线、自适应 |
|---|---:|---:|---:|
| 残差恰好为直线 | 1.00097428 | 1.00000000 | 1.00000000 |
| 较温和的混合频率 | 1.73723500 | 1.01214197 | 1.01072986 |
| 高频成分较强的混合函数 | 23.57805318 | 1.72692352 | 1.66439602 |
| 仅含 1/128 高频分量 | 6.73235539 | 1.36464858 | 1.33849362 |
| 宽多项式峰 | 1.00400401 | 1.00000200 | 1.00000190 |
| 靠近左边界，峰位 1/16 | 1.02607506 | 1.00022284 | 1.00002956 |
| 靠近左边界，峰位 1/64 | 1.13213722 | 1.00444820 | 1.00004939 |
| 靠近右边界，峰位 63/64 | 1.13213722 | 1.00444820 | 1.00004939 |

零误差对照的上下界均为零，没有计算 0/0 的倍数。残差为直线时 \(r''=0\)，直线重构余项为零，结果符合推导；展示为 1 不表示浮点运算已经严格认证。

## 为什么小幅高频仍值得关注

在 weak_high_tail 中，最高频项系数仅为 \(1/128\)，即归一化最大误差的 0.78125%。但二阶导会按频率平方放大它，残差二阶导还会再放大两次，因此它仍可能主导余项上界。

在 1000 个均匀区间下，该例直线方案中可计算的误差重构最大值 \(Z\) 约为真实最大误差的 0.999956 倍，而余项包络最大值 \(D\) 约为 0.364692 倍；两者相加给出 1.364649 倍上界。可计算部分已经很接近答案，主要的保守量来自未表示残差的包络。

这将后续问题定位得更具体：需要研究如何更紧地控制重构余项，而不是通过换一个训练结果让测试看起来更好。本轮没有证明该余项界已经最优，也没有运行更高阶残差重构。

## 相同上下界间隙要求下的成本

沿用脚本 08 的停止规则：\(U/L\leq1.2\)，或者 \(U\leq10^{-12}\)。从 32 个区间开始翻倍，最高 65536 个。下表总时间包含全部先前尝试及网格生成，为顺序运行 3 次的中位数，单位 ms。这里衡量估计的不确定程度，不是在要求真实解误差低于某个绝对容差。

| 对象 | 常数、均匀：区间 / 时间 | 直线、均匀 | 直线、自适应 |
|---|---:|---:|---:|
| 较温和混合频率 | 8192 / 6.50 | 512 / 2.33 | 512 / 5.39 |
| 较强混合频率 | 达到上限仍未满足 / 46.69 | 4096 / 5.81 | 4096 / 12.19 |
| 少量高频分量 | 65536 / 49.01 | 2048 / 4.00 | 2048 / 8.59 |
| 左边界峰位 1/64 | 2048 / 3.08 | 256 / 1.58 | 64 / 1.55 |

自适应在边界窄峰例中明显减少区间数，但生成网格有开销，时间优势比点数优势小。对全域混合振荡，均匀直线方案在本轮反而更快。计时是当前实现、硬件及少量重复下的观察，不能推广成普遍性能结论。

## 检查与实现

新增脚本：`scripts/10_function_generalization.py`。未改动公共认证算法。

- 9 个误差函数 × 8 个区间预算（16、32、64、128、256、512、1000、2000）× 3 种设置，共 216 个固定预算配置。
- 8 个非零函数 × 3 种设置，共 24 个同间隙要求配置，各顺序计时 3 次。
- 用 mpmath 60 位数值微分独立核对每个函数在 9 个位置的残差解析式，以及残差一、二阶导数是否落入对应随机非均匀网格区间的上界。
- 检查解析峰值、零边界、残差为直线时的零余项、零误差的零上下界，以及左右镜像问题在均匀网格下的一致性。
- 216 个配置的已知误差均通过上下界覆盖检查，采用浮点相对容差；有限检查不能代替对整个数值实现的证明。
