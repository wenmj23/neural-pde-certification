# 2026-11-27 毕设研究日结：一维 Poisson 连续最大误差

范围为冻结 tanh 网络、一维 Poisson，最高三次残差重构。此日结基于当时能实际读到且通过文件清单核验的记录，不代表找回了所有历史数据；学生本人尚未在 Windows 或独立主机复现。所有连续界均依赖所写数学条件、区间后端与实现正确，数值对照和独立进程读回不是形式化证明。

## 已核验的工作

- **可移植复现**：独立目录和新建 Linux Python 环境中，12个已有网络、96次固定网格证书与已公开记录的端点及节点一致；72个在线请求覆盖满足、超过和未知。脚本部分来自上轮本地材料，不能声称只凭公开仓库即可运行；首次离线安装缺 wheel，网络安装后重试成功。另对80/160位做48条有限精度检查。
- **导数细分与预算**：两批各12个已有网络中，同网格细分通常使界变窄，但固定底层导数调用预算下，细分往往增加未知。一个局部高斯尖峰控制补充对比均匀和自适应：各144个在线请求，明确判断分别19与48；尖峰是人工构造，且自适应试验在观察均匀结果后设定，不能推广。导数调用上限不等于总时间预算。
- **训练预算和反例**：两种源项、深度和种子共8组，在150与600次评估下从同一初始化分别训练；600次的8个候选训练损失均更低，全部仍到预算且未报告收敛。另一次 Jacobian 缩放配对得到严重退化案例，其条件性最大误差参考从约 4.71e-7 变为约 3.37；不说明缩放总是有害，也不解释根因。
- **边界误差与在线判断**：对精确端点差用仿射项修正误差，扩展至两个非零真解端点构造。上轮4个新网络、72请求在64段上限得到32满足、21超过、19未知；提高到256段后为36满足、28超过、8未知。之后加入带边界项的重构下界，在同一批上为36满足、32超过、4未知；这是看过结果后的探索，新增计算成本不可忽略。
- **新批配对**：在训练前本地固定配置，新训练4个网络（全部达到训练预算、未报告收敛）。对照与新下界各72个在线请求；原方法40满足、24超过、8未知，新方法40满足、26超过、6未知。两个新增判断属于同一网络的二/三次请求。没有外部预登记，种子跨深度复用，历史全局唯一性未核查；不能称严格盲测或以144请求作为144网络。单次顺序计时不支持速度结论。
- **参考与例外**：新批374次逐网格证书与12个后验条件性连续参考全部相交，但只有272次完整包含原始参考，102次仅部分重叠；以共享的精确端点信息补强参考下界后374次完整包含。这一补强不是独立下界证明，不得把原始结果写成374/374完整包含。更早的内部极值4网络案例在不同算法与后端的条件性参考下，92条对照完整包含；重复请求不等于独立网络。
- **半点任务**：半点收尾精选公开了[四次、五次 Bernstein 范数人工控制复现包](../../results/2026-11-27/half_hour_bernstein_control/)，90项有限控制通过，不是完整网络认证证明。较早的多项控制、失败和推导见对应临时交接，不表示全部已公开。
